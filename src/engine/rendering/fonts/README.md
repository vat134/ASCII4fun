Braille correction, retrieved 2026-11-15: unmodified `noto-sans-symbols-2-regular.ttf`, Noto Sans Symbols 2 version 2.008, from [Google Fonts commit 8b0a1d0](https://github.com/google/fonts/blob/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notosanssymbols2/NotoSansSymbols2-Regular.ttf). SHA-256: `7d5fb73b7ca67a6798101741f5d280a3d016a56a197afcd4199dbb57b4b82a21`. Copyright 2022 The Noto Project Authors; the complete OFL 1.1 is in `noto-symbols-license.txt`. Unifont outlines unraised Braille positions, adding visible marks in dot art. Noto covers all 256 patterns without those outlines. It adds one bundled font asset, with no runtime package, system-font lookup or external request.

Rendering policy: ASCII uses IBM at 20 px with baseline 19 px; other BMP scalars use Unifont at 24 px with baseline 21 px; supplementary scalars use Unifont Upper at the same size/baseline. These values were verified in the raster probe. Advance width is fitted to 12 px and every glyph is clipped to a 12 × 24 px cell. This preserves geometry for wide glyphs without affecting adjacent cells. Unassigned scalars follow the bundled font's missing-glyph behavior; there is no system fallback.

Exception: U+2800–U+28FF use Noto Sans Symbols 2 at 24 px, baseline 18 px. The lower baseline keeps dots 7 and 8 inside the 24 px cell. A raster regression checks all 256 glyph masks against the union of their individual raised-dot masks (two-byte antialias tolerance); a separate mixed-blank case checks fixed cell origins. This applies to Mini art and FIGlet Braille through the same renderer. Text, copy payloads, sampling and tone preparation are unchanged.
